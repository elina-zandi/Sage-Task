# Sage-Task 🌿

A cozy and aesthetic task management web app built with HTML, CSS, and JavaScript.

SageTask helps users manage their daily tasks in a clean and visually calming interface with progress tracking, task editing, completion status, and LocalStorage support.

---

## ✨ Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Progress tracking system
- LocalStorage support
- Responsive design
- Smooth animations
- Glassmorphism-inspired UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- DOM Manipulation
